# Журнал успеваемости группы

Автор: Бабаян Грач.

Программа читает ведомость сессии и считает средние баллы, задолженности и стипендии. Для каждого студента она показывает, какие результаты нужно исправить для следующего уровня выплаты.

## Запуск

Нужен Python 3.10 или новее. Из папки проекта:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

В Windows окружение активируется командой `.venv\Scripts\activate`. Если оно уже настроено, достаточно `python main.py`.

## Данные и расчет

В папке `data` находятся четыре исходных файла: `students.csv`, `plan.csv`, `grades.csv` и `rules.json`. Чтобы обработать другую группу, замените их файлами того же формата. CSV читаются с разделителем `;` и кодировкой `utf-8-sig`.

Пробелы по краям значений удаляются. Текстовые оценки распознаются без учета регистра и заменяются по словарям из JSON. Некорректные строки пропускаются; ошибки, исправления и пропущенные результаты записываются в `errors.log`.

Для каждой дисциплины учитывается последняя допустимая попытка по дате. При одинаковых датах выбирается последняя строка файла. Если в правилах отключен `last_attempt_counts`, выбирается лучший результат, при равенстве оценок - более поздний.

Средний балл считается по числовым экзаменационным оценкам. Двойка участвует в среднем, неявка не участвует. Долгом считается неудовлетворительная оценка, незачет, неявка или отсутствие допустимой записи. Форма финансирования, пороги и суммы стипендий берутся из `rules.json`.

Рейтинг строится по убыванию среднего балла, затем по числу долгов и ФИО. Сортировка идет до округления. Рекомендации содержат только действия, необходимые для следующего уровня стипендии.

## Результаты

| Файл в output | Содержание |
|---|---|
| `rating.csv` | Рейтинг и назначенные выплаты |
| `debtors.csv` | Студенты с долгами и перечни дисциплин |
| `summary.txt` | Сводка по группе, дисциплинам и рекомендации |
| `average_grades.png` | Средние баллы по экзаменам |
| `errors.log` | Ошибки и исправления исходных данных |

Сводка также выводится на экран. Доля двоек считается среди допустимых числовых оценок; все задолженности показаны отдельно. Для зачетов средний балл не вычисляется.

На исходных данных обработаны 25 студентов. Академическую стипендию получают 6 человек, повышенную - 1. Общий фонд составляет 24 000 руб. У 12 студентов есть задолженности.
