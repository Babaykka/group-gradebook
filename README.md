# Журнал успеваемости группы

Программа обрабатывает ведомость сессии: считает средние баллы, задолженности и стипендии, составляет рейтинг. Для каждого студента показывает, что нужно исправить для следующего уровня стипендии.

## Запуск

Нужен Python 3.10 или новее. Из папки проекта:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

В Windows окружение активируется командой `.venv\Scripts\activate`.

## Исходные данные

Файлы находятся в папке `data`:

- `students.csv` - список студентов и форма финансирования.
- `plan.csv` - дисциплины и вид контроля.
- `grades.csv` - оценки и даты попыток.
- `rules.json` - допустимые отметки, пороги и суммы стипендий.

CSV читаются с разделителем `;` и кодировкой `utf-8-sig`. При пересдачах учитывается последняя допустимая попытка по дате. Ошибочные строки пропускаются и записываются в журнал.

## Результаты

Папка `output` содержит результаты запуска на исходных данных:

| Файл | Содержание |
|---|---|
| `rating.csv` | Рейтинг группы и назначенные стипендии |
| `debtors.csv` | Студенты с задолженностями и перечни долгов |
| `summary.txt` | Сводка по дисциплинам, выплатам и рекомендации |
| `average_grades.png` | Диаграмма средних баллов по экзаменам |
| `errors.log` | Ошибки, исправления и отсутствующие результаты |

Сводка также выводится на экран. При повторном запуске файлы в `output` обновляются. Для другой группы замените исходные файлы в `data`, сохранив их формат.
